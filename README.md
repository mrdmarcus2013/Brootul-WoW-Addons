# Brootul WoW Addons

Public documentation and support for Brootul's World of Warcraft addons.
This repository contains documentation and issue forms, not addon source or
installable releases.

## StikTalk

[StikTalk overview, controls, installation and compatibility](docs/StikTalk.md)

StikTalk is a controller chat wheel for WoW. Public beta distribution is being
prepared; **no public addon download is available yet**. CurseForge will be the
primary distribution channel when a release is available.

[Report a bug or request a feature](https://github.com/mrdmarcus2013/Brootul-WoW-Addons/issues/new/choose).
Choose the addon in the form. Please search existing issues first and redact
account names, character/realm identities, chat content and other private details
from logs and screenshots. Never attach your complete WTF or SavedVariables files.
